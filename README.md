# タスク管理アプリ

シンプルで使いやすいタスク管理Webアプリケーションです。ブラウザで直接開くだけで動作し、タスクはローカルストレージに自動保存されます。

## 機能一覧

- **タスク管理**
  - タスクの追加・編集・削除
  - タスクの完了/未完了トグル
  - 完了済みタスク一括削除

- **タスク属性**
  - タイトル（必須）
  - 期限日（オプション）
  - 優先度（高・中・低）

- **フィルタリング**
  - すべて / 未完了 / 完了済みで絞り込み

- **並べ替え**
  - 作成順
  - 期限昇順
  - 優先度順

- **表示情報**
  - 未完了タスクの残り件数
  - 各タスクの期限と優先度

- **ローカルストレージ**
  - タスクはブラウザのローカルストレージに自動保存
  - ページをリロードしてもデータが保持される

## ローカルでの開き方

### 方法1: ファイルをブラウザで直接開く

1. リポジトリをクローン
   ```bash
   git clone https://github.com/Scythercas/cc-bench-haiku-max-r1-main-20260822-224004.git
   cd cc-bench-haiku-max-r1-main-20260822-224004
   ```

2. ファイルをブラウザで開く
   - `index.html` をブラウザにドラッグ&ドロップ
   - または、ブラウザでメニュー → ファイルを開く → `index.html` を選択

### 方法2: ローカルサーバーで実行（推奨）

```bash
# Pythonがある場合
python -m http.server 8000

# Node.jsがある場合
npx http-server
```

その後、ブラウザで `http://localhost:8000` にアクセス

## 技術仕様

- **言語**: HTML5 + CSS3 + Vanilla JavaScript (ES5互換)
- **外部依存**: なし（CDN、ライブラリ不使用）
- **データ保存**: ブラウザのlocalStorage
- **ブラウザ対応**: 最新の主要ブラウザ

## キーボード操作

- **Enter**: タスク追加または編集の確定
- **Escape**: 編集キャンセル
- **Tab**: 要素間のフォーカス移動
- すべての主要操作はキーボードのみで実行可能

## アクセシビリティ

- ARIA属性による適切なラベル付け
- キーボードのみでの完全操作サポート
- ダークモード対応（OS設定に自動連動）
- 375px の幅でも横スクロールなし

## ブラウザ要件

- Chrome / Firefox / Safari / Edge の最新版
- localStorage をサポートするブラウザ
- JavaScript 有効
